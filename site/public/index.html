Mobile-SSH-Client---Split-Keyboard

iPhone と iPad を横持ちにして、左右に分けたキーボードでシェルを挟む SSH ターミナル。縦持ちでは Mac の JIS 配列のキーボードを下に置き、シェルの面をトラックパッドにして Mac と同じ手つきで操作する。自分の Mac の tmux と Claude Code を操作するためのアプリで、通信の速さと操作感を最優先にしている。

  • 対応: iOS / iPadOS 17 以上の iPhone と iPad。横持ち（分割キーボード）と縦持ち（Mac の JIS 配列とトラックパッド）
  • 料金: 0 円（¥0）。有料の Apple Developer Program も要らない
  • 配布: App Store・TestFlight では配っていない。Mac の Xcode でソースからビルドし、無料の Apple ID の署名で入れる
  • 設定: config ファイル 1 枚（Ghostty と同じ形）。設定画面は無い

エージェントに渡す 1 行

Mac で動くエージェント（Claude Code など）に、次の 1 行を渡す。エージェントは手順書を読んでコマンドを実行し、人の手が要る所だけを頼んでくる。

https://mobile-ssh-client---split-keyboard.pages.dev/get-started.md を読んで、この Mac と iPhone に Mobile-SSH-Client---Split-Keyboard を入れて設定して

人の手が要るのは主に 5 つ: Xcode に Apple ID でサインインする、端末を USB でつないで「信頼」する、デベロッパモードをオンにする、端末で開発元を信頼する、鍵の指紋をアプリの表示と見比べる。

流れ

  1. Mac のエージェントに、上の 1 行を渡す
  2. エージェントがリポジトリを取ってきて、道具を確かめ、アプリをビルドして端末に入れる
  3. 人は、頼まれた所だけを手で行う
  4. エージェントが config に接続先を書いて端末へ送り、公開鍵を Mac に登録し、自動の入れ直しを登録する
  5. アプリを開き、ホスト鍵の指紋を確かめてつなぐ

手で進めるときも、同じ手順をそのまま読めばよい。

できること

  • 分割キーボード: US（Mac 配列の分割）とかなフリック（かな漢字変換つき）を画面の左右に置き、シェルを真ん中に出す
  • iPad のハードウェアキーボード: つなぐと画面のキーボードが消え、シェルが全面になる
  • 切れても続く: 前面に戻ったとき・回線が変わったとき・通信が切れたときに自動で繋ぎ直し、tmux のセッションに戻る。裏に回っても約 30 秒は繋いだままで、戻るとすぐ繋ぎ直す。タブごとに別の tmux のセッション（main・main-2…）で、タブを閉じても残る
  • タッチ操作: 縦ドラッグでスクロールバック（指を離したら止まる）、ダブルタップで URL・パスなどの文字列を選ぶ、長押しで選択、ピンチで倍率。選んだ文字は自動でクリップボードへ。vim・tmux・htop がマウスを求めたら、マウスとして送る
  • メディアを送る: 写真・動画・音声を Mac の受け取り箱へ送り、パスを入力行に入れる。動画は 1 枚の画像（コンタクトシート）と文字起こしにして、トークンを抑える。→ メディアを送る
  • エージェントで設定と運用: Mac で動く splitterm コマンドと MCP サーバーで、config の検査・変更・送信、公開鍵の登録、入れ直しをエージェントが実行できる。→ MCP

誰向けか

  • iPhone・iPad から、自分の Mac のシェルや Claude Code を操作したい人
  • Mac と Xcode を使える人。ビルドと入れ直しは Mac で行う（手順はエージェントが進められる）

必要なもの

もの条件
iPhone・iPadiOS / iPadOS 17 以上。iPhone XS・XR・SE（第 2 世代）以降、iPad（第 6 世代）以降
MacXcode（無料の Apple ID でサインイン）と jq
接続先SSH（macOS ならリモートログイン）と tmux。ふつうは同じ Mac
届く道iPhone・iPad から接続先の SSH に届くこと（同じ Wi-Fi、または Tailscale など）
初回だけ端末と Mac をつなぐ USB ケーブル

費用

0 円（¥0）。アプリに料金は無く、署名は無料の Apple ID で行う。このサイトも Cloudflare Pages の無料枠で配っている。接続先で使う Claude Code などの料金は、それぞれの契約による。

配布と 7 日の期限

App Store・TestFlight では配っていない。Mac の Xcode でソースからビルドし、無料の Apple ID（Personal Team）の署名で入れる。

  • 無料の署名のアプリは 7 日で起動できなくなる。Mac の launchd が 1 時間ごとに期限を見て、残りが 48 時間を切ったら自動で入れ直す
  • 入れ直しても config・鍵・ホスト鍵は残る
  • 無料の署名の制約: 1 台の端末に入れられるのは 3 本まで、App ID は 7 日に 10 個まで

安全とプライバシー

  • テレメトリ・クラウド同期・AI 機能を持たない。ターミナルの内容をディスクに書かず、外へ送らない
  • SSH の鍵は Secure Enclave で作る（端末の外に出ない）。パスワードは保存しない
  • 初めての接続でホスト鍵の指紋を見せる。変わっていたら接続を止める
  • 起動時と復帰時に Face ID（かパスコード）を求める。アプリスイッチャーでは内容をぼかす
  • アプリからコピーした内容は、他の端末へ渡さず、アプリを離れてから既定で 60 秒後に消す（選ぶと自動でコピーされるので、前面にいる間は消えない）

状態

開発中（2026-10-30 時点）。メディアの送信を含めて実装し、Mac の CI（GitHub Actions）でアプリ全体のビルドとテストを通している。実機での確認はまだ済んでいない。
